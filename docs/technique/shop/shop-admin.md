# 1. 阿祖的小店后台管理系统
本文主要介绍 阿祖的小店 后台管理系统的操作：

- 商品的分类
- 如何上架货物

## 1.1 登录系统

点击链接[阿祖的小店后台管理系统](http://shop-admin.anliu.space)，或手动输入网址`http://shop-admin.anliu.space`，进入商城的后台；

输入用户名和密码：
用户名：用户名
密码：密码

![](https://bucket.anliu.online/shop/1762675437346.png)



## 1.2 商品分类

登录后点击左侧“商品”-“商品分类”-“添加产品分类”

![](https://bucket.anliu.online/shop/1762677680370.png)

依次输入产品分类信息：
![](https://bucket.anliu.online/shop/1762677827975.png)

如果分类下面还有子分类，则点击右侧“添加子目录”：

![](https://bucket.anliu.online/shop/1762677954778.png)

依次填写子目录相关信息：
![](https://bucket.anliu.online/shop/1762678062419.png)

填写完毕后，这些分类会在小程序首页进行展示：
<img src="https://bucket.anliu.online/shop/1762678309768.jpg"  />

## 1.3 添加商品

点击左侧“商品”-“商品管理”-“添加商品”

![](https://bucket.anliu.online/shop/1762678465035.png)

输入商品信息，然后点击下一步：
![](https://bucket.anliu.online/shop/1762678970728.png)

此处商品规格必须选择多规格，否则会报错：
![](https://bucket.anliu.online/shop/1762683282816.png)

最后编辑商品详情、其他设置，然后提交，提交后商品进入仓库中，点击上架：
![](https://bucket.anliu.online/shop/1762683548444.png)

刷新小程序，点击相应的分类，即可看到刚刚添加的商品了。
<img src="https://bucket.anliu.online/shop/1762683591701.jpg"  />

至此商场添加商品结束。
